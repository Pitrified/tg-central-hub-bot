# Making a FastAPI App Cloudflare‑Tunnel Ready

Securely deriving the public base URL and trusting proxy headers

This guide explains how to make a FastAPI application work correctly
behind a reverse proxy such as **Cloudflare Tunnel**, while maintaining
good security practices.

It focuses on two key points:

1.  Correctly determining the **public base URL** of the application.
2.  Restricting which proxies are allowed to provide **forwarded
    headers**.

This avoids common issues such as broken OAuth redirects, incorrect
HTTPS detection, and header spoofing.

------------------------------------------------------------------------

# 1. Problem: FastAPI behind a proxy

When a FastAPI app runs locally:

    http://localhost:8000

but is exposed through a reverse proxy like Cloudflare Tunnel:

    Browser
       ↓
    https://yourdomain.com
       ↓
    Cloudflare edge
       ↓
    cloudflared
       ↓
    http://localhost:8000
       ↓
    FastAPI

the backend receives requests from **localhost** and sees:

    scheme = http
    host   = localhost

However the real public URL is:

    https://yourdomain.com

If the backend uses its local values, it can generate incorrect URLs
such as:

    http://localhost:8000/auth/google/callback

instead of

    https://yourdomain.com/auth/google/callback

This commonly breaks OAuth authentication flows.

------------------------------------------------------------------------

# 2. Solution overview

To solve this safely:

1.  Allow trusted proxies to pass forwarding headers.
2.  Use those headers to reconstruct the public base URL.

Cloudflare automatically sends:

    X-Forwarded-Proto
    X-Forwarded-Host

These describe the original public request.

------------------------------------------------------------------------

# 3. Step 1 --- Trust proxy headers (securely)

Add the `ProxyHeadersMiddleware` so FastAPI can read forwarding headers.

However, **never trust all hosts** (`"*"`), because attackers could
spoof them.

Instead, only trust the **local proxy** used by Cloudflare Tunnel.

### Example

``` python
from starlette.middleware.proxy_headers import ProxyHeadersMiddleware

app.add_middleware(
    ProxyHeadersMiddleware,
    trusted_hosts=["127.0.0.1", "::1"],
)
```

Why this is safe:

-   `cloudflared` connects to the app from localhost.
-   External users cannot send requests from those IPs.
-   Only the tunnel process can set forwarded headers.

------------------------------------------------------------------------

# 4. Step 2 --- Protect Host headers

Add `TrustedHostMiddleware` to prevent host header attacks.

``` python
from fastapi.middleware.trustedhost import TrustedHostMiddleware

app.add_middleware(
    TrustedHostMiddleware,
    allowed_hosts=[
        "localhost",
        "127.0.0.1",
        "yourdomain.com",
        "*.yourdomain.com",
    ],
)
```

This ensures the application only accepts requests for known domains.

------------------------------------------------------------------------

# 5. Step 3 --- Derive the public base URL

Create a helper that determines the public base URL from the request.

File example:

    src/project_name/webapp/utils/url_utils.py

``` python
from fastapi import Request

def get_public_base_url(request: Request) -> str:
    """
    Determine the public URL of the application.
    Works behind reverse proxies such as Cloudflare.
    """

    forwarded_proto = request.headers.get("x-forwarded-proto")
    forwarded_host = request.headers.get("x-forwarded-host")

    if forwarded_proto and forwarded_host:
        return f"{forwarded_proto}://{forwarded_host}"

    return f"{request.url.scheme}://{request.url.netloc}"
```

This logic:

1.  Uses forwarded headers when present.
2.  Falls back to the local request URL.

------------------------------------------------------------------------

# 6. Step 4 --- Use the base URL when generating redirects

For example in OAuth flows.

Instead of using a hardcoded redirect URL:

``` python
redirect_uri = "http://localhost:8000/auth/google/callback"
```

use the helper:

``` python
base_url = get_public_base_url(request)
redirect_uri = f"{base_url}/auth/google/callback"
```

This automatically adapts to the deployment environment.

------------------------------------------------------------------------

# 7. Result

The application now works correctly in all environments:

  Environment         Generated URL
  ------------------- ------------------------
  Local dev           http://localhost:8000
  Docker              http://container:8000
  Cloudflare Tunnel   https://yourdomain.com
  Reverse proxy       https://yourdomain.com

No configuration changes are required when moving between environments.

------------------------------------------------------------------------

# 8. Optional improvement

For maximum flexibility you can add a configuration override:

    PUBLIC_BASE_URL

Logic:

    if PUBLIC_BASE_URL is set:
        use it
    else:
        infer from request headers

This allows manual control when necessary.

------------------------------------------------------------------------

# Summary

To make a FastAPI app proxy‑safe and Cloudflare‑ready:

1.  Trust proxy headers only from localhost.
2.  Restrict allowed hosts.
3.  Derive the public base URL from forwarded headers.
4.  Use that base URL when generating external links or OAuth redirects.

This pattern ensures correct behavior behind Cloudflare Tunnel while
maintaining good security practices.
