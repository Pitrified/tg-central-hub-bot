class BotConfig(BaseModelKwargs):

### 2. Refactor `BotParams`

**File:** `src/tg_central_hub_bot/params/bot_params.py`

Current shape: `@dataclass` with `.from_env()` classmethod, `str` token, no `EnvType` dependency.

Target shape - mirror `TgCentralHubBotPaths` / `SampleParams` pattern:

- Drop `@dataclass`; become a plain class.
- `__init__(self, env_type: EnvType)` - receive env context, don't read `EnvType` from env inside.
- Read `BOT_TOKEN` from env inside `__init__` (env var reading stays in params layer only).
- Raise a custom `MissingBotTokenError` (new exception in this file) instead of bare `ValueError`.
- Store token internally as `str`.
- Add `to_config() -> BotConfig` returning a `BotConfig` with `SecretStr` token.
- Keep `__str__` masked (same format as today).
- Remove `from_env()` classmethod entirely.

```python
class MissingBotTokenError(Exception): ...

class BotParams:
    def __init__(self, env_type: EnvType) -> None:
        self.env_type = env_type
        token = os.getenv("BOT_TOKEN")
        if not token:
            raise MissingBotTokenError("BOT_TOKEN environment variable is not set")
        self._token = token
        self.parse_mode: str = "HTML"

    def to_config(self) -> BotConfig:
        return BotConfig(token=self._token, parse_mode=self.parse_mode)

    def __str__(self) -> str:
        masked = f"{self._token[:6]}...{self._token[-4:]}"
        return f"BotParams: token={masked}, parse_mode={self.parse_mode}"
```

UPDATE: store `_token` as a `SecretStr` internally to ensure token is always masked in any string representation. Do not print any portion of the token in `__str__` - just `******`. Update tests accordingly.
